# RC5 Encryption with Cellular Automata Key Generation

Verilog problem for HUD evaluation framework.

## Problem Description

Implement a 16-bit RC5 encryption module with key generation based on 8-bit Cellular Automata (Rules 90 and 150).

## Structure

- `sources/` - RTL source files
- `tests/` - Test files  
- `docs/` - Specifications
